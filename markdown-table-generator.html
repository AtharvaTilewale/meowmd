How Markdown tables work

A GitHub Flavored Markdown table is a header row, a separator row, and any number of body rows. Cells are separated with pipes. The separator row decides alignment: :--- left, :---: center, ---: right.

| Name  | Role      | Score |
| :---- | :-------: | ----: |
| Ada   | Engineer  |    98 |
| Grace | Architect |    95 |

Tips

  • Pipes inside a cell must be escaped as \|. The generator does this for you.
  • Line breaks inside cells are not supported in GFM. Use <br> if you must.
  • Padding the pipes is optional. Renderers ignore the extra spaces, but aligned source is easier to review in pull requests.
  • Need more than a table? Open the result in the MeowMD editor, or read any .md file in the viewer.
