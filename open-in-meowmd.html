Open any Markdown in MeowMD with one click

Reading a README on GitHub, a raw .md file, a Gist or a whole repository? Send it to the MeowMD viewer for a clean rendered page with an outline, search, diagrams, math and export. Two ways to install, both free.

1. Bookmarklet (works in every browser)

Drag this button to your bookmarks bar. Click it on any page to open that page's URL in MeowMD. GitHub file pages, Gists and repository pages are handled automatically.

Open in MeowMD

On mobile, or if you prefer to make the bookmark by hand, create a bookmark with this as the address:

javascript:(function(){location.href='https://atharvatilewale.github.io/meowmd/mdviewer.html?url='+encodeURIComponent(location.href);})();

2. Browser extension (Chrome, Edge, Brave)

The extension adds a toolbar button and two right-click items: Open link in MeowMD on any link, and Open this page in MeowMD. It asks for no permissions beyond the context menu and the current tab.

  1. Download the extension folder from the repository, or clone the repo.
  2. Open chrome://extensions and turn on Developer mode in the top right.
  3. Click Load unpacked and choose the extension folder.
  4. Pin "Open in MeowMD" to the toolbar. Right-click any Markdown link to use it.

The extension is open source and lives next to the app, so you can read every line before installing it.

3. Share links and the URL parameter

Any URL can be opened directly with the url parameter, which makes MeowMD easy to link from a README or an issue:

https://atharvatilewale.github.io/meowmd/mdviewer.html?url=https://github.com/user/repo/blob/main/README.md

Point it at a repository instead of a file and every Markdown document in it loads into the sidebar. For notes that live nowhere, use Copy → Self-contained link inside the viewer: the whole document is compressed into the link itself.
