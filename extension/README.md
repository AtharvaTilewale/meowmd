# Open in MeowMD (browser extension)

Adds a toolbar button and two right-click items that open the current page or any link in the
[MeowMD viewer](https://atharvatilewale.github.io/meowmd/mdviewer.html). GitHub file pages, Gists and
repositories are converted automatically.

## Install (Chrome, Edge, Brave)

1. Download this folder.
2. Open `chrome://extensions` and enable **Developer mode**.
3. Click **Load unpacked** and select this folder.

Permissions: `contextMenus` and `activeTab` only. No data is collected.
