HTML to Markdown converter

Paste HTML source, or paste formatted text straight from Google Docs, Word, Notion, Confluence or a web page. You get clean GitHub Flavored Markdown with headings, lists, links, code and tables.

What gets converted

  • Headings, paragraphs, bold, italic, strikethrough, inline code and links
  • Bulleted, numbered and task lists, including nesting
  • Tables as GitHub Flavored Markdown tables
  • Code blocks with the language when the source marks it
  • Images as ![alt](src) and blockquotes as >

Layout markup such as wrappers, inline styles, fonts and colours is dropped, which is usually what you want when moving content into a README, a wiki or a static site.

Common workflows

  • Google Docs to Markdown: select all, copy, paste into the rich text tab.
  • Web page to Markdown: select the article text in the browser and paste, or view source and paste the HTML.
  • Notion or Confluence export: paste the HTML export file contents into the HTML source tab.

Need to go the other way? Write in the MeowMD editor and use Copy HTML, or read a Markdown file in the viewer and copy it as rich text.
