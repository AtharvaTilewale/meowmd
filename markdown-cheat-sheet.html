Frequently asked

How do I make a line break?

End a line with two spaces or a backslash, or leave a blank line to start a new paragraph. A single newline inside a paragraph is ignored by most renderers.

How do I write a table?

Separate cells with pipes and add a separator row of dashes under the header. Colons in the separator row align the column: :--- left, :---: center, ---: right.

How do I add a note or warning box on GitHub?

Start a blockquote with [!NOTE], [!TIP], [!IMPORTANT], [!WARNING] or [!CAUTION] on its own line.

Can Markdown render math and diagrams?

On GitHub and in MeowMD, yes. Wrap LaTeX in $ for inline math or $$ for display math, and put Mermaid code in a fenced block tagged mermaid.
